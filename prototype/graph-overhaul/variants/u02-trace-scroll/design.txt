Trace scroll / evidence stitched into a reading column
Palette: ink #171b21; paper #f5f7f9; blue #174f9e; white #ffffff; slate #53606d. Dark uses the matching app.css role tokens.
Type: Literata for the clinical text (24/20/17px); Atkinson Hyperlegible Next for controls + source labels (15/13px). Prose maximum 66ch.
Wireframe:
[ CNL / CKC                  Guideline | Trace | Search ]
[ Follow the evidence.                                  ]
[ offline derivation notice                             ]
[ margin thread | Recommendation / Answer statement     ]
[ related recs  |   └ encoded sentence                   ]
[               |       └ verbatim guideline passage     ]
[               |           └ cropped PDF page           ]
[ next block    |                                        ]
[ scope exclusions | superseded records                  ]
Principles: connections become the physical spine of reading, not decorative edges in space. The answer has order; source follows the statement instead of hiding behind a side panel. Overview is the same scroll at recommendation granularity. Margin threads connect recommendation families by recorded concept co-mentions, explicitly not clinical implication. One bold element = the evidence spine. No canvas, force layout, pills, shadows or decorative motion.
node = a readable recommendation, answer statement, encoded sentence, document passage or PDF page excerpt.
edge = solid provenance spine linking adjacent evidence stages; margin thread = shared concept across recommendation documents (not inference).
model source = recommendations; questions.statements (ordered); documents.sentences + source + page; rules; concepts.mentions; exclusions; supersessions from guideline.json.
Mobile: margin threads become a compact related-reading row; every evidence stage stays in normal flow.
