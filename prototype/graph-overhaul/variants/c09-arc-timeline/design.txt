Principle: the printed guideline's page sequence is the coordinate system, not force placement. Dense arcs expose cross-reference clusters; exact documents and concepts stay in the adjacent list. One blue selected path against grey context. Never imply a shared concept proves a recommendation.
node = document tick; heavy tick = recommendation document.
edge = shared non-generic concept between documents; trace mode = consecutive distinct documents in the answer's citation order, explicitly not logical entailment.
model source = guideline.documents page/rec/kind + concepts.mentions; questions.statements; rules; exclusions; supersessions.
Overview sampling = 90 strongest document pairs, scored by count of shared concepts; generic patient/clinician/function verbs omitted; concepts in >45 documents omitted. All document ticks remain. Ordering = page, recommendation, id; equal spacing (not physical page distance). Adjacent page-order runs shade recommendation families; small families remain in exact document labels. Trace detail expands only cited documents across that same page-order axis, so adjacent citations on BOX 3's page remain readable rather than collapsing into one pixel. All 90 displayed overview pairs have textual reference rows.
