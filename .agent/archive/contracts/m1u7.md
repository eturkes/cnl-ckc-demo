# m1u7 — demo presentation + honest framing

Tier `docs`. Base `d5017dd`. Spine unit closing M1: the shipped surface gets its
type system, its colour system, its responsive composition, and the copy that
tells a reader what this demo is and is not.

Assurance for a `docs` unit = mechanical validators plus a consistency pass. Two
new validators enter `pnpm gate`; the visual-QA walker stays outside it because
it needs a real browser, on the `pnpm smoke` precedent.

## Decisions

- **D1 — font delivery = fontsource packages, hand-authored `@font-face`.**
  `@fontsource-variable/{atkinson-hyperlegible-next,atkinson-hyperlegible-mono,
  literata}@5.3.0`, all three OFL-1.1 with zero transitive dependencies. The
  packages' own CSS entrypoints are axis-scoped, not subset-scoped: importing
  `literata/wght.css` pulls every unicode-range subset and ships Cyrillic, Greek
  and Vietnamese to a demo whose corpus is English. `app.css` therefore declares
  its own `@font-face` rules against the six latin and latin-ext `woff2` files —
  176732 B total — and names the families `Atkinson Hyperlegible Next`,
  `Atkinson Hyperlegible Mono` and `Literata`. Hand-authoring also drops the
  `Variable` suffix the packages emit, which is a delivery detail with no place
  in a stylesheet. Both families carry NO Reserved Font Name, so using the real
  family name is permitted.
  Rejected: vendored `woff2` committed to the repo. The six package files are
  already latin and latin-ext subsets, so copying them needs no subsetting tool —
  what it needs is a read-exclusion entry for binaries, a provenance record tying
  each blob to a package version, and a licence-equality story, none of which
  buys anything over an exact dependency pin.
- **D2 — role tokens replace value tokens.** `--ink`/`--paper`/`--rule` name an
  appearance, so M4's dark theme would have to rename every use site or ship a
  token called `--paper` holding a dark value. Tokens name their role instead.
  `--field` was consumed by `QuestionCombobox` with an inline `#fff` fallback and
  defined nowhere. It is retired rather than defined: a field IS a raised surface
  here, so both fields and the listbox take `--surface-raised` and the token set
  stays one-role-one-token. Every token `:root` defines is consumed and every
  token a component consumes is defined — that closure is what `contrast:check`
  grades, and a `--field` alias would break it.
- **D3 — displayed question text stays verbatim from the catalog.** The six
  question strings are generated from the bag's compiled goals. Rewriting them
  into smoother English would make the displayed question differ from the
  question that runs, which is the one thing this demo may not do. They are
  therefore payload, not copy, and the copy validator does not grade them.
- **D4 — ACE descriptors are humanized for display.** `noun(recommendation,
  countable)` and `wh(what)` currently render as `<dt>` column labels. That is
  raw term syntax in a human-facing label. A structural formatter maps them to a
  reader's label and falls back to the raw descriptor for any shape it does not
  recognize, mirroring `humanizeGuidelineId`'s existing contract.
- **D5 — limitation copy lives in a `<details>` disclosure; attribution does
  not.** User ruling. CDC's reuse terms require the nonendorsement disclaimer to
  be "prominently and unambiguously displayed", which a closed disclosure is
  not, so attribution and nonendorsement sit in the always-visible footer and
  the disclosure carries the rest.
- **D6 — the canonical Prolog answer moves into its own `<details>`.** User
  ruling. It stays present in every settled state that has one, because it is
  the visible evidence for the project's one non-negotiable.
- **D7 — h1 = `Controlled Natural Language - Clinical Knowledge Compiler
  (CNL CKC) Demo`.** User ruling, verbatim.
- **D8 — copy is graded as data, not parsed out of markup.** All u7 prose lives
  in `src/demo/copy.ts` split into two exported records, `INSTRUCTIONS` (≤20
  words per sentence) and `DESCRIPTIONS` (≤25). The split is a committed
  editorial decision rather than a heuristic the validator has to guess, and it
  is what makes the project's two different limits mechanically checkable.
- **D9 — contrast pairs are declared, not discovered.** A checker that walks the
  rendered DOM cannot run in the gate, because jsdom has no canvas. The
  validator instead grades a committed table of foreground/background pairs,
  each naming the real use site it stands for. A pair that never co-occurs on
  screen is not in the table.

## Predicates

Gate identity at u7's close: `pnpm gate` = `kb:build && kb:asset-check &&
copy:check && contrast:check && format:check && lint && check && test && build`,
rc 0 from a clean `kb/generated`. M1 review then added `engine:check` (R35) and
`presentation:check` (U7-20, U7-26); the eleven-step chain is what `main` runs.

### F — fonts

- F1 Three families self-host from `@fontsource-variable` packages pinned at
  `5.3.0` in `dependencies`; no runtime network request fetches a font.
- F2 `app.css` declares `@font-face` for latin and latin-ext only. The built
  `dist/` carries exactly 6 `woff2` assets and no other font file.
- F3 Family names carry no `Variable` suffix.
- F4 `--font-ui` resolves to Atkinson Hyperlegible Next, `--font-prose` to
  Literata, `--font-code` to Atkinson Hyperlegible Mono, each with the previous
  system stack retained as fallback.
- F5 Every `@font-face` sets `font-display: swap`, so a slow font never blanks
  text that the engine has already produced.

### T — tokens and contrast

- T1 `:root` defines role-named tokens only; no token names an appearance.
- T2 Every custom property a component consumes is defined in `:root`; the
  `#fff` inline fallback for `--field` is gone.
- T3 `tools/contrast.mjs` parses `:root` from `src/app.css`, computes WCAG
  relative luminance and contrast, and grades a declared pair table.
- T4 Every normal-size pair reaches ≥4.5:1; every large-text and non-text pair
  reaches ≥3:1.
- T5 The validator fails closed: a pair naming an undefined token, an
  unparseable colour, or an empty table is an error, not a pass.
- T6 Negative control: perturbing one token so a pair drops below its threshold
  makes `pnpm contrast:check` exit non-zero and name the failing pair.

### C — copy

- C1 No scaffold copy survives: the h1 is D7's wordmark, and no user-visible
  string names a milestone, an unshipped feature, or an internal identifier.
- C2 The lede describes what the demo does today. The M2 trace claim and the M3
  graph claim leave the shipped surface.
- C3 All u7 prose lives in `src/demo/copy.ts` as `INSTRUCTIONS` and
  `DESCRIPTIONS`.
- C4 `tools/copy-check.mjs` grades every string in both records: ≤20 words per
  sentence for `INSTRUCTIONS`, ≤25 for `DESCRIPTIONS`, and it also grades
  `src/demo/describe.ts`, whose state wording is human-facing.
- C5 The banned-filler list (`simply`, `robust`, `seamlessly`, `leverage`) is
  enforced, and a `${...}` interpolation counts as one word.
- C6 Negative control: a 30-word sentence added to either record makes
  `pnpm copy:check` exit non-zero and name the file, key and word count.
- C7 Descriptor labels render through the D4 formatter; no `<dt>` shows
  `noun(...)` or `wh(...)`.

### A — attribution and licences

- A1 The footer states that the source material was developed by CDC, in CDC's
  own accepted form.
- A2 The footer carries a nonendorsement disclaimer, always visible, never
  inside a disclosure.
- A3 The footer states that the material is available from the agency at no
  charge, which is CDC's fourth reuse requirement.
- A4 The disclosure states that the demo does not reproduce CDC text unchanged:
  it runs a compiled projection of it. This is what keeps A1–A3 honest against
  CDC's third requirement, that a reuser not change substantive content.
- A5 The disclosure states that all 337 compiled documents carry the bag's
  `unreviewed` label, in a vocabulary whose other values are `approved`,
  `rejected`, `contested` and `stale`.
- A6 The disclosure states that the question list is fixed and that the demo is
  not for clinical use.
- A7 Each font family's OFL text ships in `dist/` under `licenses/`, byte-equal
  to the package's own `LICENSE`, and the disclosure links all three.

### R — responsive composition

- R1 No horizontal overflow at 320, 375 and 1280 CSS px in any state:
  `documentElement.scrollWidth <= clientWidth`. Baseline measured on `d5017dd`
  is already clean at all three widths, so this is a no-regression predicate.
- R2 The answer composition adapts rather than merely wrapping: the definition
  list presents label and value in a single column on narrow viewports and in a
  two-column arrangement where width allows.
- R3 Page padding scales with viewport; the fixed `4rem 1.5rem` does not survive
  at 320 px.
- R4 Long engine-authored strings stay contained; every text surface that can
  receive one keeps `overflow-wrap`.

### G — gate and evidence

- G1 `pnpm gate` rc 0 from a clean `kb/generated`.
- G2 `pnpm check` reports 0 errors and 0 warnings under `--fail-on-warnings`.
- G3 `pnpm smoke` still rc 0: the real browser answers
  `dosage-reduction-content` and the rendered canonical text equals the bag's
  committed bytes.
- G4 `tools/visual-qa.mjs` (`pnpm visual-qa`, outside the gate) walks every
  reachable state at 320, 375 and 1280 px, writes one PNG per state, and emits
  JSON carrying the overflow measurement R1 asserts.
- G5 `pnpm visual-qa` rc 0 and its JSON reports `overflow=false` for every
  width and state.

## Provenance of the honest-framing facts

- `unreviewed`: all 337 `label` rows in the bag's `release-manifest.tsv` carry
  it. Upstream `tools/goal.py:3140` counts adjudication states
  `approved`/`rejected`/`contested`/`stale`/`unreviewed`, so `unreviewed` means
  no adjudication decision was recorded, not that a check failed.
- CDC reuse requirements, quoted from `cdc.gov/other/agencymaterials.html`:
  attribution to the developing agency; a prominently displayed nonendorsement
  disclaimer; no change to substantive content; a statement that the material is
  otherwise available on the agency website for no charge.
- Fonts: both Atkinson Hyperlegible Next 2.001 and Literata 3.103 are OFL 1.1
  with no Reserved Font Name.
