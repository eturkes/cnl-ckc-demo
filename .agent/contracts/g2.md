# g2 — clinical projection (kernel)

Producer `tools/kb/network.mjs` over g1's frames → `kb/generated/graph/clinical-network.json`.
Binds `.agent/spec.md` `Decisions` (clinical concept network rulings; IMPLEMENT orientation
rulings) and `.agent/contracts/gi-orientation.md` R1–R9 + the consultant amendments. Draft for
consultant review; predicates numbered for the suite.

## Terms

- **Frame** (g1): one sentence variant — antecedent literals (each with its context: `actual`, a
  body box bound by `guideline_operator(Outer,V,Op)`, or inside `\+`), consequent heads, boxes
  `box(B)` with outer + operator, guard literals apart.
- **Occurrence** = one consequent event of one frame: key `document:sentence#variant@event-ref`.
- **Concept** = one KB entity noun across the corpus, readable form = hyphens → spaces.
  `clinician` (the guideline's generic actor) and the bare `patient`, `benefit`, `risk` are not
  concept nodes.
- **Negated condition literal** = a literal inside `\+ (…)` or in a context under a `-` box.

## Roles of an occurrence

- **Chain** = operator walk from the event's context to `actual`, outermost first; verb phrase =
  chain words (`should`, `should not` = `should`>`-`, `may`, `can`, `must`, root `-` = `it is false
  that`) + qualifier words (`guideline_qualifier` on the event) + the verb. A fact (empty chain)
  reads the verb in its finite form; the finite form must occur in the sentence's own ACE text,
  else the build refuses the sentence by name.
- **Actor** = argument 1's referent. **Target**, by the first rule that applies:
  - T1 argument 2 is an entity → its noun.
  - T2 argument 2 is a property (`is appropriate`, `is first-line`) and the event has a `for`
    phrase → the phrase's noun; the property joins the verb phrase (`should not be first-line for`).
  - T3 no argument 2, or a property with no `for` phrase → none.
- **Residual payload** = every other participant, kept on the occurrence: argument 3+, each
  prepositional phrase (preposition + noun or quantity), each property, each cardinality other
  than the default `na eq 1` (with its unit), each time annotation (interval, order, recurrence,
  frequency, window, range), each preference. Nothing in the consequent is dropped.
- **Sources**, by the first rule that applies:
  - S1 the actor is a concept (not `clinician`, not bare) → `[actor]`.
  - S2 else the condition's starts: objects (argument 2 entities) of condition events that are not
    negated literals, in body order — first events whose argument 1 is a `patient` referent
    (situations), then events whose verb is `start`, `continue`, `prescribe`, `give` or `receive`
    (treatment in course) — minus the target, deduplicated.
  - S3 else the event's `for` phrase noun, when it is a concept other than the target.
  - S4 else none.

## Buckets — every sentence in exactly one, every occurrence in exactly one

- B1 **exclusion record**: a sentence carrying `guideline_exclusion/1` heads → the boundaries view
  (condition concepts → the concept `recommendation`, `recommendations do not apply`), never a
  main-network line.
- B2 **example list**: an occurrence whose actor and every argument-2 noun end `-example` (the
  KB's own term for an example) → listed beside its sentence, searchable by each item.
- B3 **grade**: the recommendation documents' grade copulas (`guideline_grade` sentences) → the
  document's grade annotation.
- B4 **line**: sources non-empty AND target a concept → one line per source, all lines of an
  occurrence share its key, full condition, payload and rule id.
- B5 **loop**: exactly one concept among sources ∪ target → one loop on it (user ruling).
- B6 **statement**: no concept at either end, or an eventless sentence (`There is no …`) → a
  statement attached to every concept its sentence names, else to its document.
- Supersession (`guideline_supersession` record on the sentence) and guards (scope guard,
  supersession guard in the operator-edge clause) = metadata on the occurrence, orthogonal to the
  bucket.

## Line identity

A canvas line = source, target, verb phrase, payload, condition and document kind all equal;
different readings between one pair are separate lines. Each line lists every occurrence it
merges.

## Predicates (suite `tests/network-*.test.ts`, MEANING rows)

- N1 every sentence of the bag lands in exactly one bucket (B1–B6), counted against an
  independent sentence enumeration of the clause sites (not g1's frames).
- N2 every consequent event lands in exactly one occurrence and one bucket.
- N3 a line's verb phrase reproduces its chain exactly (a `should`>`-` occurrence never reads
  `should`; a `may` never `should`).
- N4 no source comes from a negated condition literal (planted: a `-` box payload and a `\+`
  payload each refused).
- N5 several sources of one occurrence share key, condition and payload.
- N6 the residual payload of each occurrence equals the consequent literals minus those its
  roles consume — re-derived by a second mapping sharing no emit code.
- N7 every line, loop and statement names its document kind from the coverage section.
- N8 the 12 exclusion records project (B1), deduplicated by clause body up to variable renaming;
  every supersession record and every guard projects as metadata; no evaluation-date exemption.
- N9 B2 items never become nodes or lines; each is reachable from its sentence and by each item.
- N10 condition text = the sentence's own ACE text (Decisions); a reduced span only under a
  structural proof (none in this unit).
