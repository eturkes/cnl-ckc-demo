# g3 — clinical codebook (`data`) — DRAFT: rubric in pilot, not frozen

Decisions (user): concepts colour by a hand-made clinical codebook — the six round-4 categories
plus as many more as make sense; two independent coders assign every concept; a concept that
fits no class says so; the legend says the KB states no categories; the colour-blind-safe
palette (`pnpm palette:check`) bounds how many classes carry their own fill.

## Method (MAIN, advisor-reviewed)

- **Code fine, fill after.** Coders assign the fine class set below (12 classes + `none`); which
  classes carry their own fill is decided from the coded class sizes. A merge after coding is a
  lookup table; a split means recoding.
- **Pilot.** 100 concepts drawn seeded and stratified by network degree — 30 of degree ≥ 5, 35 of
  2–4, 35 of ≤ 1 — concepts the rubric uses as examples left out; coded independently by
  `classifier-8` and `classifier-9` (`.scratch/agents/`, sample `.scratch/g3/pilot-ids.tsv`).
  Pass, fixed before the pilot ran: Cohen's κ ≥ 0.75 over the 100, and each coder's `none` rate
  ≤ 10%. A fail → the rubric revised from the disagreement rows and the coders' `## Rubric notes`,
  then a new pilot on a fresh sample with fresh coders.
- **Pilot result: PASS.** 97 of 100 agree, Cohen's κ 0.965; `none` 3 (classifier-8) and 2
  (classifier-9). Disagreements: P045 `norepinephrine-reuptake-inhibitor` none | opioid, P056
  `opioid-prescribing-clinician-collaboration` care | people, P076 `practice` people | care. Both
  coders run the same model lane, so their agreement shares its bias; the signal is where both
  `## Rubric notes` sections name the same gap. Clarify before the freeze, classes unchanged: a
  screening instrument (AUDIT-C) → `safeguard`, a scale or score → `measure`; bare `use` → `weighing`
  when excessive, unintended or misuse, `care` when it is the scheduled giving of a treatment; a
  `sign` or `symptom` of a condition → `condition`; a collaboration or practice → `people` when
  the sentence gives it a duty or treats it as a body, `care` when it is the act; a drug-class
  mechanism (`…-inhibitor`) → the class of the treatment it names in its sentences, else
  `nonopioid`; a likelihood or probability → the class of what it is the likelihood of; a care act
  that names no modality (intervention, prescription, medication taper) → `care`; a definition →
  `guideline`.
- **Full coding**, once the rubric freezes into this contract: two FRESH classifiers (never a
  pilot coder, which carries the pre-freeze rubric) each code every concept independently; a
  third fresh classifier adjudicates each disagreement from both codes and reasons under the
  rubric; MAIN spot-checks adjudications; κ recorded here.
- **Context per concept**: label, network degree, up to two sentences using it (lines, loops,
  statements); the 8 degree-0 concepts are scope-exclusion conditions and take their exclusion
  sentence (`cancer-related-pain`, `emergency-department-care`, `facility-discharge`,
  `hospital-care`, `observational-setting-care`, `pain-management-prescription`,
  `possible-inpatient-admission`, `sickle-cell-disease-pain`).

## Fill capacity (measured)

palette:check's rule per theme (every pair plain ΔE×100 ≥ 15, protan + deutan ≥ 8), plus what a
class colour needs: one hue across both themes (|Δh| ≤ 12° in OKLCh), light fills L 0.38–0.62
and dark L 0.62–0.86, chroma ≥ 0.07, one neutral (chroma ≤ 0.02) for `none` and shared classes,
each ≥ 3:1 against the canvas (`--surface-sunken`, `#eef1f4` / `#0d1116`). Randomized greedy over
6,000 candidate pairs, 3,000 restarts: 7 fills (6 hues + neutral). Local search for 8 left a
residual violation ≥ 7.8 in 4 seeds; 9 and 10 worse. ⇒ at most 6 classes carry their own fill;
the rest share the neutral fill and name their class in the node panel and the table view. A
per-theme search without the hue and lightness bands reaches 16 per theme only through
near-black and near-white fills, unusable as class colours.

## Rubric (pilot version)

### How to code one concept

1. A concept is one KB noun, hyphens for spaces (`opioid-taper-indication`). Read its label and the
   sentences given with it; code the THING the noun names, never the sentence's claim about it.
2. **Head rule.** A compound names what its LAST word (its head) names, the earlier words
   narrowing it: `naloxone-access` is an access, `opioid-risk-assessment-tool` a tool,
   `depression-treatment` a treatment, `opioid-taper-indication` an indication. Code the head's
   kind with the modifiers as context. A head that is a bare quality or abstraction (`benefit`,
   `risk`, `goal`, `use`) takes the class of that quality, whatever it qualifies.
3. **`-example` nouns** name an example of the thing before `-example`: code that thing
   (`as-needed-opioid-example` → an as-needed opioid → `opioid`).
4. Exactly one class. When two rows fit equally after the head rule, take the earlier row.
   `none` = no row fits without stretching; never a way out of choosing between two that fit.

### Boundaries the pilot tests

- A harm that is an event or outcome (`overdose`, `opioid-misuse`) → `weighing`; a bodily state or
  symptom (`respiratory-depression`, `constipation`) → `condition`.
- A monitoring ACT (`patient-monitoring`) → `care`; a test or record (`toxicology-testing`) →
  `safeguard`.
- A dosage QUANTITY (`opioid-dosage`) → `opioid`; its UNIT (`MME-unit-per-day`) → `measure`.
- A policy SETTER (a person or body) → `people`; a policy or law → `access`.
