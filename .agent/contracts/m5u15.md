  recorded as such with the reason. An empty `deferred` column is a claim that the registry is
  complete, and that claim needs its own evidence.

## Why a registry rather than a check

A gate step that graded every claim would have to decide natural-language truth, which no tool
in this stack can do. What a tool CAN decide is whether the cited command exists and exits 0 —
so the registry is the human-judgment layer and R3 is its mechanical half. If u15 finds a
cheap way to run R3 in the gate, that is a win; if it does not, R3 stays a recorded run with
its rc, and the registry says so rather than implying more.

R3 is also where u15 earned its keep. `pnpm release:check` **had never once completed**, and
running it is what exposed why. `tools/browser-check.mjs` started the Vite dev server with
`spawn('pnpm', ['exec', 'vite', ...])`, which builds a pnpm → vite tree, and stopped it with
`child.kill()`, which reaps the wrapper and orphans vite. The orphan held the inherited stdout
pipe open, so Node's loop never drained: `browser:check` printed `browser-check: ok` and then
hung forever — **rc 124 at a 600 s timeout**, a stray dev server left on 5173, and the composite
unable to reach `graph:check` at all. `detached: true` plus `process.kill(-pid, 'SIGTERM')` took
it to **rc 0 in 8 s with no strays**, and `pnpm release:check` then ran end to end for the first
time. Six registry rows name `pnpm browser:check` and eight name `pnpm release:check`; before
this fix every one of them cited a command that could not terminate. A check that prints its
success line is not a check that exited — now law in `.claude/rules/gate.md`.

`pnpm release:check` = `gate && kb:reproduce && smoke && browser:check && graph:check`, and the
gate chain covers `audit:check`, `secret:check`, `kb:build`, `kb:asset-check`,
`kb:export-check`, `engine:check`, `copy:check`, `contrast:check`, `presentation:check`,
`claims:check`, `format:check`, `lint`, `check`, `binding:check` and `build`. Running it once is
what makes the registry's 212 `pnpm`-rooted rows executed rather than asserted.

### Red witness

Base = `d733059`. **375 claims, and the seeded registry graded RED.**

```
node tools/claims-sweep.mjs --seed   # 375 rows written, every cell `unknown`
node tools/claims-sweep.mjs          # rc 1 — "375 rows are unadjudicated"
```

The count moved 375 → 376 → 378 → 379 DURING the unit, and that is the check working rather than
drifting: `claims:check` reads `.claude/rules/`, so documenting the check in `gate.md` and
recording u15's wave laws in `waves.md` each added a claim to the check's own input. Each
addition arrived `unknown` and reddened the gate until MAIN answered it. The seed is
idempotent — two consecutive runs are byte-identical — so the row count cannot move without a
source moving.

### What the unit had to fix in its own tooling

- **`--seed` was destructive.** It rewrote every cell to `unknown`, which made the registry
  unmaintainable: any source edit would discard every ruling. It now re-derives the row set and
  carries adjudicated cells forward, **keyed on the claim TEXT**. Ids and line anchors are
  re-issued on every run, so an id-keyed or anchor-keyed merge would hand one claim's verdict to
  its neighbour. Harvested partition files fold through the same merge
  (`node tools/claims-sweep.mjs --seed <partition.md>...`), which is what let three partitions
  seeded against a stale 375-row set land on the right claims.
- **The row block was not a table.** It shipped with no header or delimiter row, so GFM rendered
  378 rows as literal text in the one artifact meant for a reader.
- **Prettier owns `docs/`.** Three separate ways a 150-char cell slice provoked a reformat —
  a trailing space, a dangling `\` escape that swallows the row delimiter, and an odd backtick
  count whose unmatched opener reflows the rest of the row — all now settled in `cell()`, which
  is idempotent so a cell written by an earlier form still settles to the same merge key. The
  table itself ships under `prettier-ignore`: at this cell width, column padding rewrites every
  row to 451 characters and `format:check` would never agree with the seed again.
