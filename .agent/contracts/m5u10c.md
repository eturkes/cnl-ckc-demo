# u10c — empty-table guards + the two unowned thresholds

Tier: `kernel`. The subject IS verification integrity: every predicate here decides whether
another check can still refuse a wrong input. Nothing downstream re-checks a checker.

Dispatch: `prod-guards` (the five declared-table guards + their controls) + `test-owners`
(C7 `PREPOSITIONS`, C8 `SEPARATION_PX`); MAIN rules on both and edits `.claude/rules/gate.md`.

## The defect

Five declared tables grade NOTHING when they parse empty, while the step still prints its
count — a check that stopped reading its own input and a clean tree emit the same green. Every
existing firing input builds its OWN synthetic table, so none proves the REAL one non-empty.
`tools/engine-check.mjs:151` `check(files.length > 0, …)` is the idiom each guard copies, and
`tools/binding-check.mjs` `gradeTable` (added at u10b, `8425f9f`) is the shape: the guard takes
the table as a PARAMETER so the control can feed it the real table emptied.

Two shipped thresholds have no owner at all: nothing fails when either drifts.

## Predicates

Each guard must name the table in its refusal, and each control must drive the check's OWN
grader over the REAL input emptied — never a synthetic fixture built beside it.

- **G1 `binding:check` `REQUIRED`.** Literal `Object.freeze([…])`. Emptied, the inventory
  grades 0 while the controls still fire and the step prints `0 required binding cases passed
  across 0 suites`. Route `REQUIRED` through the existing `gradeTable(REQUIRED, 'REQUIRED',
  suites)` and add its control beside `LIFECYCLE`'s.
- **G2 `engine:check` `CONTROLS`** (`tools/engine-check.mjs:61`). Literal four-object array.
  Emptied, no child control runs and an otherwise-green summary ends `0 controls fired`
  (`:283`). Guard at `:151` beside `check(files.length > 0, …)`, before any predicate work.
- **G3 `copy:check` `FILLER`** (`tools/copy-check.mjs:25`). Literal four-word array, passed
  only to the REAL English grade. Emptied, the controls survive on their synthetic `['the']`
  filler, so rc stays 0 and the step still prints `285 en strings pass … 3 controls fired`.
  Guard before the real `gradeEnglish` call at `:280`.
- **G4 `secret:check` tree targets** (`tools/secret-check.mjs:54`, inline `['**/*']`). Emptied,
  secretlint 12.3.1 exits **2** with `Not found target files` and the wrapper exits 1 under
  `secret found in the working tree` — rc is already nonzero but the refusal names the WRONG
  thing, which is the defect here. Hoist the list to a named `TREE_TARGETS` and guard it before
  the spawn, so the refusal names the table.
- **G5 `kb:asset-check` `SCAN_ROOTS`** (`tools/kb/check.mjs:16`). Point one root at a path that
  does not exist and `walk()` returns `[]` for it (`:60`); its loop grades nothing, yet the
  success line still reads `sibling-path scan clean over 6 roots` (`:226`). Bind each root's
  paths at `:177` and guard per root, naming `SCAN_ROOTS` and the root.
- **C7 `PREPOSITIONS` owner** (`tools/kb/clinical.mjs:102`, a 13-token complement grammar).
  Read only by `splitComplement` (`:126`, `:133`); drift repartitions an action's object
  against its ordered modifiers, changing grouping and the emitted `modifier/2` terms while the
  reassembled source text can stay byte-identical. Owner = `tests/clinical-records.test.ts` T9,
  whose frozen source span currently BEGINS after the set and the splitter (`:453`). Extend it
  to start at `const PREPOSITIONS =` and run through `splitComplement`, so any vocabulary drift
  reddens while T9's existing parsed and presentation hashes keep proving corpus behaviour.
- **C8 `SEPARATION_PX` owner** (`tools/graph-probe/probe.ts:134`, value 3). Sole cutoff in
  `distinct()` (`:136-143`) for R1 midpoint collisions; the render loop counts
  `parallelSeparated` (`:334-353`), the reading returns it (`:383`) and `graph:check` makes R1
  green only when it equals `parallelPairs` (`tools/graph-check.mjs:319-323`). Raising it
  false-fails R1; **zero makes coincident strokes read as distinct, so R1 passes vacuously
  while the renderer regresses.** Owner = `graph:check` R1: require the probe-reported cutoff
  to be exactly `3`, plus an absolute boundary control where 2 px collapses and 3 px separates.
