# u12 — scope-aware projection

Tier: `kernel`. The projection decides what the graph MEANS: a dropped negation renders a
recommendation as its clinical inverse. Nothing downstream re-checks it — u13 grades the SHOWN
conjunction against the final renderer, but it can only show what the projection hands it.

Dispatch: to be named at dispatch time; MAIN rules and wires the gate.

## What ships

`src/graph/model.ts` reads u11's scope data and preserves it through the concept projection.
Today it drops both fields on the floor: `parseEdge` (`:182-194`) ALLOWLISTS edge fields, so
`edge.scope` never survives parsing, and `parseSemanticGraph` (`:220`) ignores the top-level
`scopes` table entirely. Teaching the reader to parse them is this unit's first move.

u11 shipped (commit `32c6a84`, contract `.agent/contracts/m5u11.md`):

- `schemaVersion` **2**; top-level `scopes` array of **1,263** records sorted by `id`, each
  `{ id, chain, operator, document, sentence, reference }`.
- `chain` = the resolved outer context, **ORDERED OUTERMOST FIRST**. Depth maxes at 2; the root
  atom `actual` and an unresolved rule variable each terminate a chain as a literal element.
- `operator` = one of `-` `should` `may` `can` `must`. Census: `should` 857, `-` 156, `may` 156,
  `can` 85, `must` 9.
- `edge.scope` = an INDEX into `scopes`, present on operator-bearing edges and absent otherwise.
  17,667 edges carry one; all 1,193 operator edges do; 0 indexes are unresolvable.
- **7 scope records are unreferenced and that is legal** — user ruling, u11 S3. 71 operator
  contexts carry no edge at all (64 negation, 7 `can`); see `.agent/deferred.md`. The
  projection must not assume every record is reachable from an edge.

## The existing projection

Measured surface (`.scratch/agents/map-scope.md`): `src/graph/model.ts:37-47,343-354,382-429,
609-619,674-824`. The concept projection filters `operator` edges and non-`condition supports`
`implies` edges, and `operator-context` is absent from `CONCEPT_NODE_KINDS`.

**100% of the surviving projection is scope-stripped** (`.claude/rules/graph.md`): all 5,796
retained edge occurrences and all 2,381 groups belong to a scope-bearing source unit, so there
is no small subset to repair. Projection = 1,288 nodes / 2,381 grouped edges out of 2,901 /
20,964; the filter drops 15,168 occurrences and dedup removes another 3,415.

**User ruling, binding** (`.claude/rules/graph.md`): keep the concept-first projection and carry
negation + modality as EDGE STATE. No `operator-context` node returns to the concept view, and
**no edge may read as a claim the source denies**.

## Predicates

- **P1 parse.** `parseSemanticGraph` accepts the v2 asset's `scopes` table and `parseEdge`
  preserves `edge.scope`, both validated at the boundary the way every other field is: a
  malformed record, an out-of-range index or a non-integer scope is a `GraphDataError` naming
  the field. An unreferenced record is NOT an error.
- **P2 ordered scope survives projection.** Every projected edge preserves its relation AND its
  ordered scope. Grouping and dedup key on the scope sequence, so two occurrences that differ
  only in scope order stay distinct groups rather than collapsing.
- **P3 the six in-scope review reds go GREEN.** `tests/graph-semantics.review.test.ts` merges
  into the primary tree from branch `wt/rev-sem-2` and the six named below pass.
- **P4 the two accepted-open reds stay out of scope.** They are adjudicated `fail(med)` and
  deferred; u12 neither fixes nor deletes them. If they pass incidentally, say so; do not
  target them, and do not let them widen this unit.
- **P5 no `operator-context` node in the concept view.** The user ruling holds after the
  change: scope rides the edges. `CONCEPT_NODE_KINDS` gains no member.
- **P6 fail-closed at the boundary, not silently in the projection.** Whatever the projection
  cannot represent is refused where it is read, never dropped without a trace — that is the
  shape S13+ describes, and while S13+ itself stays deferred, u12 must not add a NEW silent
  drop of its own.
