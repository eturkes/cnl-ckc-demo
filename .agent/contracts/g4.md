## Probe facts the design rests on (`.scratch/g4/`, desktop, 1-min load 10–27)

- Rendered label boxes (`page/`, real Chromium, all 1,334 labels + 234 loop readings, zooms
  0.02–6): Cytoscape's intrinsic label height = 13 + (lines − 1) × 15.6 exactly at every zoom; its
  intrinsic width exceeds the HarfBuzz advance sum by ≤ 0.70 px at zoom ≤ 0.1, ≤ 1.36 px at zoom 1,
  and by about `z` px above zoom 1 (4.19 px at 4×, 5.76 px at 6×) — screen-fixed text drawn at a
  model size below 13 px drifts. Hence the maximum zoom is 1 everywhere: every label reveals by 1,
  and nothing gains from zooming past it.
- `labelBounds` adds Cytoscape's own 2 model px per side, which scales with zoom and is never
  drawn: the rendered box is the intrinsic size + outline.
- Main-component fcose with every non-anchor below the acute anchor (`relativePlacementConstraint`):
  0 above the row, width ≈ 9,500 model px. With the anchors anywhere inside that width their labels
  overlap at a 288 px canvas's box-aware fit (consultant-13: ±3,300 needs zoom 0.0274, the fit allows
  ≤ 0.0257). With acute and chronic at the row's ENDS (side constraints, `D` = half the first pass's
  width) the slack at a 288 px fit is fixed by the three label widths, whatever `D` is; placing
  subacute to split it in proportion to the clearance each side needs gives anchor `sep` 0.01786
  against the full fit 0.01861, a 4% margin the build refuses by name when lost. fcose leaves a
  few box overlaps at zoom 1 (max `sep` 4.2–4.4); a push pass oscillates (4 left after 300 sweeps);
  a downward stacking pass leaves none.
- The built asset (`kb/generated/graph/clinical-network-layout.json` at the g4 commit): 1,334
  nodes, 432 components, 392 loop blocks, 2,939 focus views, 640,453 B, extent 9,822 × 8,003 model
  px, `D` 4,901, max `sep` 0.9997; at the full fit the reveal rule shows 4, 5 and 21 labels on
  288 × 320, 343 × 440 and 1152 × 660. A layout run takes 17–36 s on this desktop at load 10–20 (a
  validated cache hit 0.25 s before focus views were graded on hits); `kb:reproduce` holds two
  forced builds byte-identical, the layout asset included.

## Geometry (screen px unless named model px; one module, `src/network/geometry.ts`, imported by the build through Node's type stripping and by g5)

- **Metrics**, declared constants (MAIN's look calls, open at g5's live review): font Atkinson
  Hyperlegible Next, `wght` 600, 13 px, line height 1.2; wrap width 130 px; outline 3 px; width
  tolerance 2 px; dot diameter 10 px, pain-anchor dot 18 px (`R` = 9, the largest radius); label gap
  4 px; pair gap `G` 4 px; line width 1.5 px; canvas margin 12 px; maximum zoom 1. Every on-screen
  size is screen-fixed: g5 styles each as `px / zoom`.
- **Label** = the concept's `label`, wrapped at word boundaries to the wrap width by HarfBuzz
  advances over the shipped `latin` woff2 decompressed to sfnt at `wght` 600; a word wider than the
  wrap width keeps its own line, never cut; the lines joined by single spaces equal the label.
  `W` = widest line + 2 × outline + tolerance; `H` = size + (lines − 1) × size × line height + 2 ×
  outline (13 + (lines − 1) × 15.6 + 6), as Cytoscape draws it. Floating-point results are graded
  within 1e-9 against an oracle that orders its arithmetic differently; the bit-level equalities
  this contract states (`sep` symmetry, byte-identical reruns) stay exact.
- **Loop block**: the concept's distinct loop readings, sorted, each wrapped like a label, stacked
  under its label after one label gap — shown for a focus view's subject alone.
- **Box** of node `i` at zoom `z`, point `(x_i, y_i)` model px: horizontally centred, width
  max(`W_i`, 2`R`); vertically from `y_i·z − R` (its dot) to `y_i·z + R + gap + H_i` (+ gap +
  block height for a focus subject). Every box shares the top offset `−R`, so overlap is monotone in
  zoom.
- **Overlap** (the oracle, gap-aware): two boxes overlap at `z` when they come closer than `G` on
  both axes. **Separation zoom** `sep(i,j)` = `min(zx, zy)`, `zx = ((wi+wj)/2 + G)/|x_i−x_j|` with `w`
  the box width max(`W`, 2`R`), `zy = (h_upper + G)/|y_i−y_j|` with `h_upper` the full box height of
  the node with the smaller `y` (∞ for a zero difference); boxes overlap at `z` iff `z < sep(i,j)`.
  `sep` evaluates each pair in one order (by id), so `sep(a,b)` and `sep(b,a)` agree to the bit.
- **Reveal**: priority = the three anchors (acute, subacute, chronic), then line degree (the line
  records incident to the concept, not distinct neighbours) descending, then id. `reveal_i` = 0 for an anchor; else the largest `sep(i,j)` over higher-priority `j` with
  `sep(i,j) > reveal_j`, or 0. A label shows at zoom `z` iff `reveal_i ≤ z`.
- **Full frame** `frameFull(layout, canvas)` → `{zoom, pan}` (canvas ≥ 288 × 320): every dot and
  every label shown at that zoom inside the canvas less the margin; this zoom is the canvas's
  minimum zoom.

## Focus views (`src/network/focus.ts`, shared by the build and the page)

- **Sets**: `concept:<id>` = the concept (the subject) and every concept a line joins it to, with
  those lines; `rule:<document>:<sentence>` = the concepts of every line and loop with an occurrence
  from that sentence, with those lines, no subject. A pain view is its anchor's concept view. A
  traced answer's set comes from its live proof in the page (g5).
- **Layout** `layoutFocus({ subject, ids, lines }, sizes, block)` → `{ subject, nodes: [{ id, x, y }] }`
  at zoom 1 (screen px), the subject (else the first id) at the origin: direction edges = each line
  once in (source, target) order unless it closes a cycle (`directionEdges`); ≥ 3 concepts → seeded
  fcose (`FOCUS_SEED`, declared options) with each box as its body and every direction edge as a
  top/bottom constraint; 2 → the start above its lead, or side by side; then downward stacking and
  direction rounds alternate until no box pair overlaps and every direction edge points down
  (refused by name after `FOCUS_ROUNDS`). The subject's loop block rides under its label. An empty
  set (a trace whose proof touches no network concept) is refused by name (`FocusError`, `no
  concept`): the page shows its own empty state, never a view.
- **Frame** `frameFocus(view, sizes, block, canvas)` → zoom 1; the view's boxes centred when they fit
  the canvas less its margin, else the subject's box (no subject: the topmost node's) centred at the
  top margin; the reader pans for the rest.
- The build lays out every concept and rule set (2,939 on this bag, a few seconds) into the asset's
  `focus` (`{ <key>: [id, x, y][] }`), so opening one runs no layout in the page; the page runs the
  same function for a trace once its proof finishes (its time is a g4b budget).

## Interface (what tests and g5 call)

- `src/network/geometry.ts`: `METRICS`; `ANCHORS`; `labelWidth(advance)`, `labelHeight(lines)`;
  `boxOf(node, block?)` → `{ left, right, top, bottom }` offsets from the node's screen point;
  `overlaps(a, b, zoom, blocks?)` (the oracle); `sep(a, b, blocks?)`; `byPriority`; `reveals(nodes)`
  → `[{ id, reveal }]` in priority order, nodes in any order (`{ id, x, y, W, H, degree, anchor }`);
  `frameFull(layout, canvas)`. Pure: no DOM, no font, no Node built-ins; the asset carries every box
  size. Node imports it by type stripping (`allowImportingTsExtensions` in `tsconfig.json`).
- `src/network/focus.ts`: `FOCUS_SEED`, `FOCUS_ROUNDS`, `FocusError`, `seeded(seed, run)`,
  `directionEdges({ subject, ids, lines })` → `[source, target][]`, `layoutFocus(input, sizes, block)`,
  `frameFocus(view, sizes, block, canvas)`; `sizes` = `Map<id, { W, H }>`, `block` = the subject's
  `{ W, H }` or null. Imports Cytoscape + fcose (headless), so the page bundles them with the network.
- `tools/kb/layout.mjs`: `focusSets(network)` → `[{ key, subject, ids, lines }]` sorted by key;
  `measureLabel(text)` → `{ lines, W, H }` (HarfBuzz); `layoutNetwork(network)`
  → the asset body (in-process; the child runs it); `validateLayout(body, network)` → problems
  (G1–G5); `closureOf(network)` → `{ digest, parts }`; `buildLayout(network, { force, deadlineMs,
  postLayoutMs, child?, cacheDir?, closureFiles? })` → `{ path, bytes, cached, cacheFile }` through
  the cache and the bounded child — `path` = the asset's path under `kb/generated`
  (`graph/clinical-network-layout.json`) like every build asset, `cacheFile` = the absolute path of
  the cache entry it read or wrote; refusals are `LayoutError`s (`name` `'LayoutError'`), a focus
  layout's `FocusError`s; `child` names a child module (the planted held timer and endless layout), `cacheDir` a
  test cache.
- `kb/generated/graph/clinical-network-layout.json`, manifest kind `network-layout`
  (`MANIFEST_VERSION` 10), read by g5 lazily at its own URL beside the network asset: the page draws
  only when the layout's `envelope.network` equals the network asset's `envelope`, else it shows its
  named failure state; g5 sets the minimum zoom to `frameFull`'s for its canvas (refit on resize)
  and the maximum to `METRICS.maxZoom`. The boundaries view lists conditions, which are no concepts:
  g5 owns its layout. Geometry is locale- and theme-independent: every concept label is ASCII,
  which `measureLabel` enforces by refusing a code point the shipped face lacks.

### Interface facts (answering tester-11)

- `METRICS` = `{ font: { family, weight, size, lineHeight }, wrap, outline, tolerance, dot,
  anchorDot, radius, labelGap, pairGap, lineWidth, margin, maxZoom }`, the values in `## Geometry`.
- `blocks?` (for `overlaps` / `sep`) = `{ a?: { W, H } | null, b?: { W, H } | null }`: the loop block
  of `a` and/or `b` when it is a focus subject; `boxOf(node, block?)` takes `{ W, H }` and an
  optional `{ W, H }`.
- `frameFull(layout, canvas)`: `layout` = `{ nodes: { id, x, y, W, H, reveal }[] }`, `canvas` =
  `{ width, height }` → `{ zoom, pan: { x, y } }`; a model point `(x, y)` draws at screen `(x·zoom +
  pan.x, y·zoom + pan.y)`.
- Child protocol: `node <child> <input.json> <output.json>`; input = `{ network, envelope }`; the
  child writes the asset JSON (`{ schemaVersion, envelope, ...body }`) to the output path, prints
  one stdout line `{"event":"layout-end"}`, and exits 0 on its own. The parent's whole-run deadline
  starts at spawn, its post-layout deadline at that line; their refusals are `LayoutError`s whose
  messages contain `whole-run deadline` and `post-layout exit deadline`.
- `focusSets(network)`: sorted by `key` (code-unit order); each set's `ids` sorted the same way,
  `lines` = the network's line records in network order (parallel records repeat), `subject` = the
  concept id for a `concept:` set, `null` for a `rule:` set.
- `directionEdges(input)`: identical (source, target) pairs once; candidates taken in code-unit
  order of `source + "\u0000" + target`; a candidate is skipped exactly when its target already
  reaches its source through the edges kept so far (so the kept set is acyclic and maximal in that
  order); self-lines and lines leaving the set never enter.
- `seeded(seed, run)` is synchronous: it patches `Math.random` for `run` alone and restores it in
  `finally`, a throw included.
- Closure: parts in order `network` (sha256 of `JSON.stringify` of the network asset as given),
  `font`, `geometry`, `focus` (`src/network/focus.ts`), `layout`, `child`, `lockfile` (sha256 of each
  file's bytes; `CLOSURE_FILES`
  lists `[name, path]`, paths resolved from the layout module's own repository, never the cwd),
  `runtime` (sha256 of `` `${process.version} ${process.platform} ${process.arch}` ``); digest =
  sha256 of the lines `` `${name}:${hex}\n` `` joined in that order. `closureOf(network, files?)` and
  `buildLayout`'s `closureFiles` take another `[name, path]` list, so a test points the file parts
  at temp copies it may change.

## Layout (build time, `tools/kb/layout.mjs`, run in a bounded child)

Declared constants live in `layout.mjs` (`SEED`, `D0`, `ROW_GAP`, `COLUMN_GAP`, the fcose options,
`DEADLINE_MS`, `POST_LAYOUT_MS`); a tie always breaks by id.

1. Components by union-find over lines (loops join nothing). The anchors' component = the main
   component; the anchors in two components refuse the build by name.
2. Main component, two seeded fcose passes (`randomize` from a seeded PRNG patched over
   `Math.random`, restored in `finally`; each node sized by its box at zoom 1 + `G`, placed by its
   box centre, point = centre − (gap + H)/2): pass 1 fixes the anchors at `D0` = 1,000 apart with
   every other node below the acute anchor; pass 2 sets `D` = half pass 1's x extent and adds side
   constraints, so every other node lies between acute (left end, x = −`D`) and chronic (right end,
   x = `D`); subacute sits at x = −`D` + 2`D` × `a` / (`a` + `b`), `a` and `b` the clearances its
   label needs from acute's and from chronic's ((w₁ + w₂)/2 + `G`), so the narrowest canvas's slack
   splits in proportion.
3. Overlap pass at zoom 1: every non-anchor whose point is not below the row moves just below it;
   then a downward stacking pass in (`y`, id) order moves each node overlapping a box placed before
   it to just below that box — x never moves, a move passes one box for good, so it ends with no
   overlapping pair and the side constraints intact.
4. Every other component: one unconstrained seeded fcose run gives the shapes of those with 3 or
   more nodes, each then stacked like step 3; a pair sits side by side; a single node alone. An
   explicit shelf packer places them below the main component's box: sorted by node count
   descending, then box height, then smallest id; rows no wider than the main component (a wider
   component sits alone in its row); `ROW_GAP` and `COLUMN_GAP` apart.
5. Coordinates rounded to 0.01 model px, THEN every pair re-checked at zoom 1 and the reveals
   computed; canonical JSON.

## Build + cache

- `kb:build` runs the layout in a child process under a whole-run deadline (`DEADLINE_MS` 450 s = 3
  × two passes of the spike's slowest loaded pass, 75 s) and a 10 s post-layout exit deadline (the
  spike measured 43–46 ms; the margin covers the load envelope); the
  parent grades the artifact (G1–G5, G8) before writing. A held timer or a layout past its deadline
  refuses by name.
- Cache: `node_modules/.cache/cnl-ckc-demo/layout/<closure digest>.json`; a hit skips the child and
  is graded G1–G5 and G8 like a fresh artifact; any closure part changed misses. `kb:build --force`
  bypasses it, so `kb:reproduce`'s two forced builds recompute the layout. Like every producer, a
  layout, geometry or font edit with an unchanged bag needs `kb:build --force`: the build's own
  manifest cache keys on the bag inputs and returns before the layout runs, and `kb:asset-check`,
  re-deriving through the layout cache, refuses the stale asset by name (`.claude/rules/kb-build.md`).
- CI restores the cache directory with `actions/cache`, keyed on a superset of the closure files
  (the bag archive, `tools/kb/**`, `src/network/geometry.ts`, `package.json`, the lockfile); the
  entry's own closure digest decides a hit.
