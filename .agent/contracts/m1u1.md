# acceptance contract — M1.u1 export→PVM producer

Tier = `kernel`. MAIN authors every file below in the primary tree. This
contract is the single decision surface: every downstream artifact (red suite,
review checklist, differential script) decides against it, not against MAIN's
code.

Source clause (`.agent/roadmap.md`, M1 u1):
> Project-local safe BagIt verifier and idempotent image producer, generated
> manifest, forced QLF fallback, `kb:build` + `kb:asset-check` wired into the
> gate. The final runtime payload is u1's own output.
> Accept: sibling absent + clean cache → two runs verify every digest, reject
> traversal/tamper, emit contract-equivalent manifests, and live-load schema v1
> with exactly 337 documents; forced QLF passes the same live contract; a
> sibling-path scan over build inputs and runtime assets is empty.

## P — testable predicates

Numbered predicates. Every red test, review row and differential check binds to
one of these. `MUST` = failure is a defect.

### P1 input verification
- P1.1 `kb:build` MUST verify `kb/cnl-ckc-kb-*.tar.gz` against its `.sha256` sidecar before parsing a single byte of the archive, and abort nonzero on mismatch.
- P1.2 The reader MUST parse the archive entirely in memory. No code path may write an archive member to the filesystem.
- P1.3 The reader MUST reject, with a distinct typed reason each, an entry that: is not a regular file or directory; carries an absolute path; contains a `..` path segment; contains a NUL or control character in its name; duplicates an earlier entry name; resolves outside the bag root; declares a size inconsistent with the remaining stream.
- P1.4 Rejection MUST be refusal, not repair: no rejected name is rewritten, stripped or normalized into an accepted one.
- P1.5 BagIt verification MUST assert `bagit.txt` declares `BagIt-Version: 1.0`, and MUST verify every entry in `manifest-sha256.txt` AND every entry in `tagmanifest-sha256.txt`.
- P1.6 Verification MUST be complete in both directions: every payload member under `data/` appears in `manifest-sha256.txt`, and every manifest entry exists in the archive. A payload file present but unlisted is a rejection, not a warning.
- P1.7 A single flipped byte in any payload file, any tag file, or any manifest line MUST abort the build nonzero.

### P2 production
- P2.1 The producer MUST feed the 337 `pl/` payload files in a deterministic order fixed by the code, and MUST record that order's identity in the manifest as a digest of the exact concatenated input.
- P2.2 Before saving the image, the producer MUST assert inside the building engine that `guideline_schema_version` reports schema 1 and that exactly 337 `guideline_document/3` documents are loaded, and MUST abort nonzero otherwise.
- P2.3 The producer MUST capture engine stderr/diagnostic output during consult and MUST abort nonzero when the payload produces an error diagnostic. [spike S11 supplies the exact observable signal]
- P2.4 The producer MUST emit both `kb.pvm` and `kb.qlf` in one run; neither artifact may be produced from a different input than the digest recorded in the manifest.
- P2.5 The manifest MUST be written last, after every asset is on disk, so an interrupted build never leaves a manifest that claims artifacts it did not produce.

### P3 idempotence and the manifest
- P3.1 Two consecutive `kb:build --force` runs from a clean cache MUST emit contract-equivalent manifests. Contract-equivalent = every field equal except fields the spike proves nondeterministic; those fields are named explicitly in `src/kb/manifest.ts` and excluded by name, never by a blanket comparison. [spike S1/S2 fixes the exact field set]
- P3.2 A second `kb:build` without `--force` MUST NOT rebuild when the recorded input digest, toolchain version and asset digests all still match; it MUST still verify every digest it skips rebuilding for.
- P3.3 A cache hit MUST be invalidated by any of: changed input digest, changed `swipl-wasm` version, missing asset, asset digest mismatch, manifest schema mismatch.
- P3.4 The manifest MUST record, at minimum: manifest schema version; source bag filename and sha256; BagIt payload/tag file counts; input file count, byte count and concatenated-source sha256; `swipl-wasm` version; per-asset path, byte count, sha256 and kind; and the live-verified contract values (schema version, document count).
- P3.5 Every number in the manifest MUST be observed during the run that wrote it. No constant is copied from documentation or from a previous manifest.

### P4 live contract
- P4.1 A freshly built `kb.pvm`, loaded through the documented loader, MUST report schema version 1 and exactly 337 documents.
- P4.2 The forced-QLF path MUST satisfy the identical assertions as P4.1 from the `kb.qlf` artifact. The switch that forces it MUST be explicit and testable.
- P4.3 The live contract MUST be asserted by a committed test that boots the real generated artifact. It may not read a fixture, a recorded answer, or a constant standing in for engine output.
- P4.4 The live test MUST fail if `kb/generated/` is absent, rather than silently skipping.

### P5 gate and hygiene
- P5.1 `pnpm gate` MUST run `kb:build` and `kb:asset-check`, ordered so that no later member can pass on artifacts that were never verified.
- P5.2 `kb:asset-check` MUST re-verify manifest ↔ disk digests, recompute the input digest from the vendored bag, and MUST NOT rebuild.
- P5.3 A sibling-path scan over build inputs and runtime assets MUST be empty. Scope = `tools/`, `src/`, `kb/generated/`, `vite.config.ts`, `package.json`, `index.html`. Scope explicitly excludes `.agent/` and `CLAUDE.md`, where the sibling is legitimately discussed.
- P5.4 The whole pipeline MUST succeed with the sibling directory absent or unreadable. No code path may reference `../cnl-ckc`.
- P5.5 Generated paths MUST be added to `.gitignore` and to the read-exclusion controls, PARTITIONED per the project `CLAUDE.md` rule rather than duplicated (M1 review X17): a gitignored generated path goes to `.claude/settings.json` `permissions.deny` ALONE, because Serena's `git_ignore=true` already excludes it and an `ignored_paths` entry would be redundant state; a tracked, non-gitignored path goes to both halves; an LSP-hostile path that must stay readable goes to `.serena/project.yml` `ignored_paths` alone. Every deny rule MUST match a real path on disk.
- P5.6 `pnpm gate` MUST be green end to end from a clean checkout with `kb/generated/` deleted.

## I — invariant surfaces (spot-check even on a green run)

- The 337 count and the schema version are never hard-coded as a pass condition in production code; they are read from the engine and compared against the manifest.
- No test asserts a digest constant that the same test computed from the artifact it is verifying.
- The hostile-bag fixtures are synthesized by the test, never committed as opaque binaries.
- `kb:asset-check` cannot pass when `kb/generated/` is empty.

## G — gate identity

Decisive commands MAIN reruns before the unit closes:
1. `rm -rf kb/generated && pnpm gate` → rc 0.
2. `pnpm kb:build --force && cp kb/generated/kb-manifest.json /tmp/m1.json && pnpm kb:build --force && diff <equivalence check> /tmp/m1.json` → contract-equivalent.
3. `pnpm test` with the forced-QLF switch set → same live contract.
4. Sibling-path scan → empty.
