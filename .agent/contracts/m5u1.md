# m5u1 — source-fragment/antecedent compiler

tier `kernel` · flags `oracle` `prod` · base `22053ef` · est I=70K → M=185K
Depends —. Split seam: fragment rendering ↔ antecedent/premise compilation.

## Problem

`tools/kb/clinical.mjs:clinicalArtifacts` emits FINISHED `clinical_advice/3` facts:
the runtime goal is a fact lookup, no inference runs (ledger S1). Its companion
`clinical_advice_source/4` carries **one** `site(Line,Head)` per sentence — the first
`guideline_*` line after each `% S<n>:` marker (`sourceClauses`, `bySentence.has(key)
→ continue`). `proof.mjs` replays those single sites as childless leaves (S3).

u1 replaces what FEEDS the renderer. It emits, per selected sentence, the source
fragment, the **complete** ordered antecedent site chain, and the hypothetical
premises that apply the guideline's universal quantification. It changes no rendered
byte and runs no evaluator — u2 owns evaluation, u3 owns runtime assembly.

## Design rulings (MAIN)

**D1 — no spike wave.** The mechanism is settled by committed planning probes, not
open: `wt/res-m5-1` `27eff5d` ruled assumption-MI-at-cap-2 the winner over six
mechanisms (48/48 scenarios, no writes, both negative controls 72/72), and
`wt/res-m5-2` `1542794` demonstrated exact-site fragment gating end to end on
rec01:S2. A spike would re-decide a decided question. Recorded so a reviewer reads
the omission as a ruling, not an oversight.

**D2 — site enumeration = the CASES recipe, ported into `clinical.mjs`.** Scan
`payloadDocuments(files).source`; `% file:.../pl/<doc>.pl` opens a document,
`% S<n>:` with `n > 1` opens a sentence, and **every** subsequent `guideline_*` line
is a content site `{line: index+1, head, body}`. Reference:
`git show wt/res-m5-1:tests/m5-inference-support.mjs`. This differs from the shipped
`sourceClauses` in exactly one way — it keeps every clause per sentence, not the
first — and that difference is the 48 → 686 gap.

**D3 — one antecedent per sentence, enforced.** All clauses compiled from one
sentence share one body. The producer computes the distinct body set per sentence and
**throws** when it is not a singleton, matching the probe's `multiple antecedents`
guard. A future corpus that violates it fails the build rather than emitting a
premise set that belongs to no clause.

**D4 — premises are compiled unconditionally and grounded at build time.**
`m5_prepare` chose between native proof and assumption AT RUNTIME (`once(B) -> As=[]
; ...`). Build time cannot know that, so u1 emits the decomposed positive literals
unconditionally and **u2's evaluator decides** whether to discharge each natively or
assume it. Decomposition = conjunction split; `\+ G` contributes no premise (its
truth is not assumable). Free variables ground to `'$clinical_hypothetical'(Doc,S,N)`
with repeated variables mapping to the same skolem, preserving the antecedent's
equality relationships exactly as `groundHead` does for heads. A compound skolem, not
`groundHead`'s inert atom, because u5 must display explicit hypothetical origin.

**D5 — ONE ground head form, both data and executable. Corrected by measurement.**
D5 originally required two head forms — raw/executable for the gate chain, grounded
for records — on the assumption that a ground head cannot drive `clause/3`. **That is
false.** `clause/3` unifies a ground query head against a stored head holding
variables, binding them to the skolems; `call(Body)` then demands exactly the
grounded premises. Measured on rec01:S2 with heads ground before consult: bare KB →
`no`; with `guideline_entity(actual,Skolem,clinician,countable)` +
`guideline_cardinality(actual,Skolem,na,eq,1)` → `yes` with
`L = [496,497,498,499,500,501,502,503,504]`, zero diagnostics.

Consequences, all binding:
- Heads and premises ground at build time through **one shared skolem map per
  sentence**, so the antecedent's variable sharing survives as a shared constant and
  records may be separate facts without losing it.
- The probes' runtime grounding (`term_variables` + `m5_ground`) is unnecessary on
  this path; u2 inherits a simpler evaluator.
- Grounding must tokenize like the existing `groundHead` (quoted atoms copied byte
  for byte, repeated variables sharing one replacement). A naive substring replace is
  unsound against atoms such as `'acute-pain'`.
- `groundHead`'s existing `'clinical_variable_N'` output stays exactly as-is for the
  existing `site(Line,Head)` in `clinical_advice_source/4`; u1 adds a skolem-factory
  variant rather than changing the shipped one.

**D6 — u1 ships generated program text, u2 ships the interpreter.** `clinical.mjs`
already emits Prolog source as a string; the gating clause is generated text and
belongs to u1. The meta-interpreter that proves it under query-local assumptions is
u2. That is the u1/u2 seam.

**D7 — `clinical_advice/3` keeps being emitted.** u1 does not delete it: it is the
byte oracle P1 grades against, and u3 — not u1 — is where the runtime stops reading
it. Deleting it in u1 would break the byte-identity predicate that makes u1 safe.

**D8 — no separate `prod-m5u1` teammate.** u1's validator-gated artifact is the
expected-record corpus, and an independent reimplementation is its natural producer,
so `orc-m5u1` produces it behind MAIN's validator. Recorded because the unit carries
the `prod` flag; the flag is honoured by the validator + independent producer, not by
a second teammate.

**D9 — every `_` grounds fresh.** A bare `_` is a distinct variable at each occurrence,
so `groundTerm` keys it on a per-occurrence synthetic key instead of the token text; a
token-keyed map would fuse two independent slots into one equality and make the gate
demand more than the source clause does. Measured 0 occurrences across the 686 selected
heads and 28 distinct bodies, so the corpus never exercises it and P1 stays byte-identical
— it is correctness for the next corpus, and a synthetic-input row is what proves it.

**D10 — unsupported control forms fail the build.** Only `,`, `\+` and `true` carry an
assumption semantics. `;`, `->` and `*->` at a conjunct's top level would be emitted as if
they were literals, so `premiseGoals` throws `unsupported control form <op>` instead.
Measured 0 in all 28 distinct antecedents. An unsound premise is exactly the class M5
exists to remove, so this fails closed rather than emitting one.

**D11 — a CR in a consumed content line fails the build.** A CR survives the LF split and
rides into the emitted head, where the trailing-period slice leaves it inside the term
rather than removing it. `contentSites` rejects it for the lines whose bytes enter the
image. `payloadDocuments` is shared with every other producer and stays unguarded — the
guard sits where the bytes are consumed. Measured 0 CR lines in the payload.

## Emitted surface

Added to `clinicalArtifacts`' generated helper source. Names are project-idiomatic
(`clinical_*`), never the probes' throwaway `m5_*`.

```prolog
clinical_rule(Doc, S, Rule).                  % fragment data; Rule = groupTerm() of the single-sentence group
clinical_premise(Doc, S, N, Literal).         % grounded hypothetical premise, N = ordinal
clinical_use(Line, Head) :- clause(Head,Body,Ref),
    clause_property(Ref,file('/prolog.pl')),
    clause_property(Ref,line_count(Line)), call(Body).
clinical_gate(Doc, S, Rule, [L1,…,Ln]) :-     % generated per sentence; ground heads inline
    clinical_use(L1,H1), …, clinical_use(Ln,Hn), clinical_rule(Doc,S,Rule).
```

**No separate `clinical_site/4`.** An earlier draft carried one fact per site; it
duplicated all 686 ground heads (~137 kB) for no gain, because the gate clause must
carry them inline to stay executable. The line list lives in `clinical_gate/4`'s HEAD,
so `clause(clinical_gate(D,S,R,L),_,_)` enumerates every site **without executing the
gate** — which is exactly what P3's coverage check needs. P2 and P3 already key on
`clinical_gate/4`, so no predicate changes.

**Fragment granularity.** `clinical_rule/3` is PER SENTENCE, while `answerTerm`'s
groups merge sentences sharing a consequent, so a fragment is not a group. Render it
by feeding the single parsed sentence through the frozen `groupClauses` + `groupTerm`
— reuse, not reimplementation, so P7 holds by construction. Reassembling fragments
into the 12 canonical terms is u3's job, not u1's.

`clinical_advice/3` and `clinical_advice_source/4` are unchanged (D7).

- **P5 — one antecedent per sentence.** A sentence whose clauses carry more than one
  distinct body fails the build with a specific error (D3).
- **P6 — premise soundness.** For every `(Doc,S)`, the emitted premises are exactly
  the positive literals of that sentence's antecedent, grounded per D4, with repeated

- **P7 — frozen surfaces.** `parseAdviceSentence`, `clauseSource`, `groupClauses`,

  rebuild-equality check (`rebuilt !== original` → throw) still rejects a sentence it
  cannot rebuild byte-for-byte. It is the single byte guard; `groupTerm` is a
  renderer, not a guard (ledger A3 cites both — only one is a guard).
- **P9 — gate green.** `pnpm gate` rc 0 from a clean `kb/generated`.
- **P10 — budget declared.** The payload/PVM/QLF byte delta u1 adds is measured and

## Measured constraint handed to u2

**4 of 48 gates cannot be resolved natively.** rec01:3, rec02:3, rec02:8 and rec05:4
exhaust a 200,000-inference limit even with ONLY their own premises asserted — so it
is not global-premise contamination. The control rec01:2 proves under the identical
shape returning exactly `496..504`. The corpus's recursive rule-head chains are the
cause, which is precisely why the ruled mechanism is a **depth-capped** assumption
meta-interpreter rather than native resolution; `wt/res-m5-1`'s mechanisms d/e/f prove
all 12 documents at cap 2. u1's records are therefore correct as data, and
**terminating on these 4 is u2's acceptance obligation, not u1's.** Reproduce:
`node .scratch/m5u1/bounded.mjs`.

## Resolved divergence — 38 vs 48 fragments

**Not a defect: two granularities of one dataset.** MAIN emits one `clinical_rule/3`
per selected content SENTENCE (48); `orc-m5u1` rendered the shipped `clinical_answer`
GROUPS (38), which merge sentences sharing a consequent. Reassembling MAIN's 48 by
consequent — conditions concatenated in sentence order — reproduces all 38 shipped group
terms byte for byte across 12 documents, **0 divergences** (`node
.scratch/m5u1/fragments.mjs` rc 0). The per-sentence form is the strictly finer one, and
it is what u5's premise display needs, since a premise belongs to a sentence's antecedent
and a merged group has several. The rerun also proves u3's reassembly is derivable from
u1's records alone.

## T14 rulings (MAIN)

`test-m5u1` phase 1 raised ten divergent contract readings. Seven are accepted as
proposed, three are corrected against the implementation's measured behaviour. Phase 2
encodes THESE, not the proposals.

1. **Multiplicity/ownership — accept.** Exactly 48 `clinical_rule/3` + 48
   `clinical_gate/4`; all 686 lines unique, each under its owning `(Doc,S)` only, line
   list ascending in payload order.
2. **P4 identity — accept.** Compare the full keyed `{line,head,body}` source vector, not
   a line multiset; P3 is that vector's line projection.
3. **New-record order — CORRECTED.** Every new record kind emits in QUESTION/SOURCE
   order, not payload order: `clinical_rule`, `clinical_premise` and `clinical_gate` all
   run rec01,02,03,04,06,07,08,09,10,11,**05**,12, identical to the existing
   `clinical_advice` order, because one loop emits all five kinds. Per-record internals
   are payload order (gate lines ascending, premises in antecedent literal order).
   Inter-kind layout is non-contractual beyond deterministic bytes.
4. **Marker/domain — accept, mechanism named.** The producer's marker regex is the prefix
   form `^% S<n>:`; all 60 markers in the 12 selected documents carry text, so the
   reference's stricter `% S<n>: <text>` form and the prefix form agree on this corpus.
   The ACE↔PL bijection is enforced mechanically, not by a new check: a selected sentence
   with no content site throws, and P3's both-ways equality is what rejects a PL sentence
   no ACE sentence claims. Test it AS the bijection, never as a bare count.
5. **Shared-map traversal — CORRECTED.** Order is heads first in payload order, THEN
   premises left-to-right after NAF removal; the map resets per `(Doc,S)`. Skolem
   ordinals are opaque identifiers: their only contract is determinism plus sharing, so
   no test may assert a specific ordinal for a specific variable name.
6. **Two ordinals — accept.** Independent zero-based counters: premise `N` = literal
   position in the antecedent; skolem `N` = first-occurrence position in the shared map.
7. **Anonymous/duplicate leaves — CORRECTED to fresh-per-occurrence (D9).** Not "each `_`
   is fresh" as an unimplemented expectation and not a rejection: `groundTerm` now grounds
   each `_` to its own skolem. Duplicate positive literals keep their order and
   multiplicity, a ground leaf emits unchanged, `true` emits none.
8. **Unsupported controls — accept, fail closed (D10).**
9. **Malformed/error scope — accept, category pinned.** Fail closed on: ACE CR, empty ACE
   sentence, missing/`METADATA`-only ACE, zero-site selected sentence, unterminated quoted
   atom, >1 distinct antecedent (P5), unsupported control form (D10), CR in a consumed
   content line (D11). P5's message is pinned exactly; the rest grade by regex.
10. **P7/budget — accept.** P7 = base-span hashes PLUS behavioural snapshots (48 parsed
    clauses, 12 canonical presentations, 12 `deriveProvenance(...).source.text`). P10
    measures the payload, PVM and QLF deltas from `22053ef` with no failure ceiling; the
    suite asserts the measurement REPRODUCES across two derivations rather than pinning a
    magnitude, so a corpus change cannot make it lie.
