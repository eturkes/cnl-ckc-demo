# acceptance contract — M1.u2 Prolog engine worker

Tier = `kernel`. MAIN authors every code file below in the primary tree. This
contract is the single decision surface: every downstream artifact (red suite,
review checklist, differential script) decides against it, not against MAIN's
code.

Source clause (`.agent/roadmap.md`, M1 u2):
> Typed client + dedicated module Worker owning `swipl-wasm`, PVM load via Vite
> `?url`, plain-DTO protocol, term decode/encode, canonical display text.
> Accept: dev server and built output both boot to a 337-document engine; every
> query closes; the decoder round-trips the documented term shapes including the
> `foo(bar,7)`→`foo([bar,7])` and `1r3`/`3r1` traps.

## D1 — RULED by MAIN from wave-1 spike evidence

Both spikes cleared 11/11 traps and full re-query identity on the real image, so
the ruling turns on their risk rows, not their capability rows.

| id | decision | evidence |
| --- | --- | --- |
| D1.1 | Term boundary = **JS-side decoder**. The worker decodes swipl-wasm's native binding values into a discriminated-union `PlTerm` before anything crosses the boundary. | Decisive: PL requires a hand-written JS grammar for canonical Prolog text, and that 197-line parser already preserved only 1/3 adversarial forms — SWI's float `1.0Inf` decoded to an atom SILENTLY (`spike-m1u2-pl.md` `s.risk`). Silent term corruption falsifies the project's one non-negotiable. JS's worst case is a *bypass* (native JSON re-entry turning `'$guideline_id'/5` into arity 1), which a mechanical check prevents (`spike-m1u2-js.md` `s.risk`). JS also costs 0 new dependencies and 0 boot consults against PL's shipped 853 B helper plus 38.7–81.6 ms consult (`s.deps` both). |
| D1.2 | Solution delivery = **one correlated batch per query**. Streaming is deferred to `.agent/polish.md`. | Both `s.protocol` rows agree streaming is cheap (0.0414 vs 0.0345 ms/query) but is NOT cancellation: a queued callback stayed blocked through a 94.65 ms synchronous `next()`. Cancellation is u3's, and ≤7 solutions need no progressive paint. |
| D1.3 | Display text = `term_string/3` with `quoted(true), numbervars(true), ignore_ops(true)`, measured at 0.0437 ms/binding. `print_message` is diagnostic-only. | `spike-m1u2-js.md` `s.display`: 7/7 real answers matched `write_canonical`, while `message_to_string` produced `Unknown message: '$guideline_id'(...)` for 0/7. Confirmed independently by `spike-m1u2-pl.md` `s.display`. |

D1.1 carries mandatory controls, each a predicate below: decode inside the worker
before any DTO is built (P3.9), never re-enter a native value (P3.10), fail closed
on an unrecognized tag (P3.11), and re-encode only through the engine's own helper
constructors (P3.7).

## P — testable predicates

Numbered. Every red test, review row and differential check binds to one.
`MUST` = failure is a defect.

### P1 worker ownership and boot
- P1.1 The engine MUST live only inside the worker. No main-thread module may import `swipl-wasm`, transitively included.
- P1.2 The worker MUST load the saved PVM obtained through a Vite `?url` import, and MUST NOT consult the 337 source documents at runtime.
- P1.3 On boot the worker MUST read schema version and document count OUT of the booted engine and MUST compare them against `kb-manifest.json`. A mismatch is a typed failure, not a warning.
- P1.4 Boot failure (fetch failure, malformed image, engine init throw) MUST surface to the client as a typed terminal state. It MUST NOT hang a pending request and MUST NOT surface as an unhandled rejection.
- P1.5 Exactly one engine boot MUST serve every subsequent query in a session; a second query MUST NOT re-boot.

### P2 protocol
- P2.1 Every payload crossing the boundary MUST survive `structuredClone` unchanged. No class instance, function, or `Error` may cross.
- P2.2 Every request MUST carry a client-generated id, and every response MUST echo it. An unmatched response MUST be a typed protocol violation, never a silent drop.
- P2.3 Every request MUST terminate in exactly one terminal outcome — success or typed failure. No request may remain pending after its terminal response. ["every query closes"]
- P2.4 Request and response types MUST be declared once and imported by both sides. Neither side may restate the shape.
- P2.5 A worker-level failure (`onerror`, `messageerror`, in-worker unhandled rejection) MUST reject every in-flight request with a typed failure rather than leaving them pending.

### P3 term decode and encode
- P3.1 The decoder MUST produce a discriminated union that a TypeScript `switch` can exhaust, and the exhaustiveness MUST be compiler-enforced.
- P3.2 The decoder MUST distinguish a compound's argument vector from a compound holding a single list argument. `foo(bar,7)` and `foo([bar,7])` MUST decode to different values. [the trap named in the source clause]
- P3.3 Rationals MUST round-trip with their orientation intact: `1r3` MUST NOT decode to, or render as, `3r1`.
- P3.4 An atom and a Prolog string MUST decode to distinguishable values, even when both carry identical text.
- P3.5 An integer outside the IEEE-754 safe range MUST NOT decode to a lossy `number`.
- P3.6 An unbound variable MUST decode to an explicit variable value, never to `undefined`, `null`, or a fabricated atom.
- P3.7 Decode → encode → re-query MUST be an identity over every shape the KB actually produces, proven against the real image.
- P3.8 The real KB answer shape `'$guideline_id'(product,'cdc2022-opioid-rec02',1,ref(1),[])` MUST round-trip exactly: 5 arguments, `$`-prefixed quoted functor, nested `ref(1)`, and a genuine empty-list final argument.
- P3.9 Decoding MUST happen inside the worker, before any value is placed in a DTO. No native swipl-wasm value may reach the protocol boundary.
- P3.10 A native engine value MUST NOT be re-entered into a query. Re-encoding MUST construct fresh terms through the engine's own helper constructors. [`spike-m1u2-js.md` `s.roundtrip`: native compound instances must not re-enter directly]
- P3.11 An unrecognized or unsupported binding tag MUST fail closed with a typed decode error. It MUST NOT be coerced to a string, silently dropped, or passed through.
- P3.12 Production code MUST NOT `JSON.stringify` an engine value. Native JSON is the one measured corruption path: it turned `'$guideline_id'/5` into arity 1 with `ref([1])` and serialized `1r3` as `3r1`.

### P4 canonical display text
- P4.1 Every decoded solution MUST render to display text that re-reads as the same term.
- P4.2 Quoting MUST be correct for atoms needing it: `$`-prefixed, hyphenated, and mixed-case atoms MUST come back quoted such that the text re-reads.
- P4.3 Display text MUST be derived, never assembled from a hard-coded template per predicate.

### P5 live contract and tests
- P5.1 A committed test MUST boot the real generated `kb.pvm` and prove 337 documents at schema 1. It MUST NOT read a fixture standing in for engine output.
- P5.2 A committed test MUST execute a real KB goal end to end through the shipped client surface and prove the 7 category-A solutions.
- P5.3 The anti-hard-coding probe MUST hold: inject a `dynamic/1`-declared overlay clause, re-run, and assert the result CHANGES. A test that passes with the engine stubbed out is a defect.
- P5.4 No production module may import from `queries/answers`, transitively included.
- P5.5 The live tests MUST fail, not skip, when `kb/generated/` is absent.

### P6 gate and hygiene
- P6.1 `pnpm gate` MUST be green end to end from a clean checkout with `kb/generated/` deleted.
- P6.2 The dev server AND the production build MUST both boot to a 337-document engine, each proven in a real browser. ["dev server and built output both"]
- P6.3 Any new generated or cache path MUST be added to `.gitignore` and to the synced read-exclusion pair (`.claude/settings.json` `permissions.deny`, `.serena/project.yml` `ignored_paths`).
- P6.4 No code path may reference `../cnl-ckc`; the sibling-path scan MUST stay empty.

## I — invariant surfaces (spot-check even on a green run)

- 337 and schema 1 appear in production code only as values read from the engine and from the manifest, never as literal pass conditions.
- No test asserts a constant that the same test computed from the artifact it is verifying.
- The main-thread chunk in `dist/` contains no engine bytes — provable from the build output, not asserted from the source.
- Term fixtures used by the round-trip battery are synthesized or read from the live engine, never committed as expected-answer blobs.
- The worker's message handler is reachable as a pure function, so a test can drive it without a DOM Worker.

## G — gate identity

Decisive commands MAIN reruns before the unit closes:
1. `rm -rf kb/generated && pnpm gate` → rc 0.
2. `pnpm test` → the term battery and both live tests green against the real PVM.
3. Browser smoke on the dev server AND on the built output → both report 337 documents.
4. Forbidden-import checks → main thread free of `swipl-wasm`, production free of `queries/answers`.
5. Sibling-path scan → empty.

## Q — probe-corpus seed

Term shapes the red suite must cover: `foo(bar,7)` vs `foo([bar,7])` · `1r3` and
`3r1` · atom vs string with identical text · integer above `2^53` · negative and
zero integers · float · empty list `[]` · improper list · unbound variable ·
variable shared across two arguments · nested compound `ref(1)` · `$`-prefixed
quoted functor · hyphenated atom `'category-A-recommendation'` · operator term ·
empty-atom `''` · atom containing a quote · deeply nested compound · the full
`'$guideline_id'(product,'cdc2022-opioid-rec02',1,ref(1),[])` answer shape.

Protocol cases: unmatched response id · duplicate response for one id · worker
dying mid-request · boot failure before any request · two concurrent requests ·
a request issued before boot completes · a malformed goal · a goal with zero
solutions.
