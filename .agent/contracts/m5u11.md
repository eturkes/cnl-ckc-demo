## What ships

`tools/kb/graph.mjs` emits, beside the existing `nodes`/`edges`, a **versioned top-level
`scopes` table** keyed from the clause AST, with each edge carrying a `scope` reference into
it. Scope is never inlined per edge: 1,263 contexts across a 1,936-occurrence corpus dedupe
hard, and inlining pays the full string cost on every one of them.

Measured surface (`.scratch/agents/map-scope.md`, rows G1/G3/G4):

- Producer today emits `{path, bytes, model}`; `model = {schemaVersion, nodes, edges, stats}`;
  edge = `{id, kind, source, target, label, document, sentence, line, predicate}`. The AST
  arrives through `parseClauseSites(files)` (`tools/kb/graph.mjs:10-21,172,211-232,437-450`).
- Signal = `guideline_operator(outer, reference, op)` in each ClauseSite head or body
  (`tools/kb/provenance.mjs:25-27,374-438`; `tools/kb/graph.mjs:83-96`). Arg 0 = the OUTER
  context, arg 1 = this context's identity, arg 2 = `-` or the modality.
- Asset `kb/generated/graph/semantic-graph.json` = 8,184,964 B raw. Its gzip size depends on
  the compressor: **325,989 B** through node `zlib.gzipSync` at default options, 327,090 B
  through the `gzip` CLI, which stores the filename and mtime in its header, and 286,015 B at
  `{ level: 9 }`. map-scope's 327,090 B was the CLI reading; S5 grades the node one.

## Pinned schema — MAIN's ruling, both agents code to it

Neither agent may renegotiate these. A shape disagreement between the emitter and the cases is
what a pinned schema exists to prevent.

- Top-level `scopes` = an ARRAY of records, emitted beside `nodes`/`edges`, sorted by `id`.
- Scope record = `{ id, chain, operator, document, sentence, reference }`.
  - `chain` = the resolved outer context, **ORDERED OUTERMOST FIRST**, as an array of strings.
    The root atom `actual` and an unresolved rule variable each terminate a chain as their own
    literal element.
  - `operator` = one of `-` `should` `may` `can` `must`.
  - `sentence` = a positive integer or `null`, matching the existing edge convention.
- `edge.scope` = the INDEX (number) of that record in `scopes`, present on operator-bearing
  edges and ABSENT otherwise. Never an inlined object: 1,263 contexts over 1,936 occurrences
  dedupe hard, and inlining pays the full string cost on every occurrence.
- `GRAPH_SCHEMA_VERSION` 1 → **2**, in `tools/kb/graph.mjs:10` AND `src/graph/model.ts:1`.
  Bumping only the producer makes the SHIPPED reader refuse the new asset and reddens the gate,
  so the pair moves together. That one-line bump is the ONLY `src/` edit this unit makes.
- gzip is measured by node **`zlib.gzipSync` at default options**. The compressor is part of
  the number: the `gzip` CLI reads 327,090 B and `{ level: 9 }` reads 286,015 B on the same
  bytes, so a case that pins neither grades a figure the budget was never set against.

### Callable names — pinned, so the emitter and the cases bind to one seam

- **S2 needs NO new export.** `deriveSemanticGraph(files, parsedClauses = parseClauseSites(files))`
  references `files` in its DEFAULT PARAMETER ONLY — measured, one match in the whole function
  — so `deriveSemanticGraph(new Map(), constructedClauseSites)` drives the REAL derivation off
  a constructed `ClauseSite[]`. Grading the production path beats grading a helper written to
  be gradable, so S2 takes this seam and no `deriveScopes` is exported.
- **S7 = `validateSemanticGraphAsset(model)`**, exported from `tools/kb/graph.mjs`, returning
  `string[]`: empty = clean, and each entry NAMES the offending table or record. That is the
  shape `requireFiring`'s `grade` callback already consumes and the shape
  `tools/kb/reproduce.mjs` `differences()` established, so the firing input needs no adapter.

## Predicates

- **S1 census.** The emitted `scopes` table represents **1,263** operator contexts, of which
  **156** carry `-` (negation) and **857** carry `should`. The remaining 250 are `may` 156,
  `can` 85, `must` 9. A case asserts all five counts from the EMITTED asset, not from a
  fixture, and 156 + 857 + 156 + 85 + 9 = 1,263 is asserted as the partition it is.
- **S2 ordered scope.** Every scope record preserves its outer context as an ORDERED
  sequence, not a set. Two edges whose contexts share members in a different order get
  different scope records. **The corpus cannot grade this alone** — depth maxes at 2 and only
  70 contexts nest at all, so a set-valued implementation passes a census of the real asset
  almost everywhere. S2 is therefore graded on CONSTRUCTED input: feed the derivation two
  contexts whose chains are permutations of one another and require two distinct records with
  distinct ids. That is u10c's law applied forward — a predicate that cannot fail is green for
  the same reason a correct one is.
- **S3 edge linkage — ONE-WAY, user-ruled.** Every operator-bearing edge references exactly one
  scope record and every `edge.scope` index resolves. An UNREFERENCED scope record is
  permitted. The count of unreferenced records is pinned as a literal, so it reddens on drift —
  the direction that no longer holds is relaxed, never deleted, because an assertion that
  cannot fail is worth nothing (u10c).

  **User ruling.** The shipped graph leaves **71 operator-context nodes with no edge** — 64 of
  them negation (`-`), 7 `can`, i.e. 41% of the corpus's 156 negation contexts. They are the
  body-level scopes like `guideline_operator(actual, C, -)` whose identity binds at query time,
  with entities asserted inside `C`. prod-scope's first implementation closed the gap by
  emitting 71 additional body edges, moving totals to 21,035 / 1,264. The user ruled **leave
  them orphaned**: the graph's edge population stays exactly as shipped at 20,964 total and
  1,193 operator edges. `validateSemanticGraphAsset` therefore must not treat an unreferenced
  record as invalid. Queued in `.agent/deferred.md` with its acceptance check.
- **S4 no new node kind.** `stats.byNodeKind` gains no key. Scope rides the EDGES — user
  ruling, `.claude/rules/graph.md`: no `operator-context` node returns to the concept view.
- **S5 budget.** The emitted asset, compressed by node `zlib.gzipSync` at **default options**,
  is at most **508,572 B** — today's 325,989 B plus the ruled +182,583 B. The case reads the
  number off the real artifact and names the compressor it used, because the CLI and `level: 9`
  each answer a different number on the same bytes.
- **S6 versioned.** `GRAPH_SCHEMA_VERSION` rises 1 → 2 in the producer and the reader together,
  and a reader pinned to version 1 refuses the new asset BY NAME rather than silently ignoring
  `scopes`. Silence is the measured default here, not a hypothetical: `parseEdge` allowlists
  edge fields and `parseSemanticGraph` ignores unknown top-level keys, so v1 drops `scopes` and
  `edge.scope` without a word. The case asserts the refusal text names both versions.
- **S7 structural validator.** One validator grades the emitted asset's shape — every scope
  record well-formed, every reference resolvable, every count non-zero — and it REFUSES an
  asset whose `scopes` table is empty, naming it. That guard is u10c's law applied forward: a
  new declared table is not born able to grade nothing.

## Grading

`pnpm kb:build` then `pnpm gate` rc 0. S1, S2, S3, S5 and S6 are vitest cases over the built
asset; S7 is the validator plus its firing input, reported in the step's success line and
joined to `.claude/rules/gate.md` `Firing inputs`.

**The seven cases do NOT join `binding:check`'s declared inventory, and that is a tier
decision, not an omission.** `REQUIRED` is the answer-path plus KB-integrity roll call and
`LIFECYCLE` holds the claims the view makes about a run reaching a terminal state; scope
records are neither, and a third declared register for a `data`-tier unit buys `kernel`-weight
assurance the tier does not call for. u12 does add that third table — `MEANING`, for the
`kernel`-tier projection cases — and u11's seven still stay out of it: the reason was the tier,
not the table's absence. What makes the guard durable instead is S7: the validator
runs inside `kb:asset-check` with a `requireFiring` control over the REAL table emptied
(`tools/kb/check.mjs:159-175`), so the table cannot silently stop grading. The seven cases
still run in the gate's single suite pass and a failure still reddens it.
