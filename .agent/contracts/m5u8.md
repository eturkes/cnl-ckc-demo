## Measured — the five UNVERIFIED capabilities

| # | capability | verdict |
| --- | --- | --- |
| 1 | vis automatic parallel-edge separation | **YES** via `smooth: {type:'dynamic'}` — 9/9 + 6/6 + 2/2. **So does Cytoscape** with `curve-style: bezier` (both cy arms 9/9 + 6/6 + 2/2). The shipped arm's 0/9 + 0/6 + 0/2 is `curve-style: straight` — ONE style property, not a renderer capability. |
| 2 | vis label visibility under `drawThreshold` | **BITES.** The gate is `scaling.label.drawThreshold` (default 5), nothing under `font` (`vis-network/dist/vis-network.js:21040,21171`): `viewFontSize = font.size * scale` is skipped below `drawThreshold - 1` and faded toward opacity 0 at exactly `drawThreshold`. On `worst-bounded` with positions frozen (settle → `getPositions()` → rebuild at `physics:false`, so only label drawing can move a pixel; `drawThreshold:100` is the positive control): desktop scale 0.412 → 4.12 px → `faded`; mobile scale 0.139 → 1.39 px → `skipped`. Cytoscape's `min-zoomed-font-size` defaults to 0 — labels are always drawn at full opacity. |
| 3 | vis `selectNodes` isolation via `highlightEdges:false` | **YES.** `getSelectedEdges().length` = 0 with `false` vs 11 with `true` on a 14-edge path. `edge.options.color.color` is unchanged either way — vis applies selection colour at draw time, so a colour read is the wrong observable; the selected-edge SET is the right one. |
| 4 | vis per-edge dashes | **YES.** `edges.update([{id, dashes:[6,4]}])` changes the canvas and touches one edge; restoring `dashes:false` returns the byte-identical image. |
| 5 | bundle delta, six peers resolved | cytoscape+fcose **735,350 B raw / 188,374 B gzip**; vis-network **701,201 B raw / 177,055 B gzip**. vis is **−34,149 B raw / −11,319 B gzip (−4.6% / −6.0%)** — on a chunk that is lazily imported on graph activation. |

## Ruling (user, binding)

vis-network is **rejected**. It loses on the metric the swap was proposed for: half the label
size at both viewports, labels suppressed outright on the densest view, and 10.2–12.3 s of
layout there against Cytoscape's 146–224 ms. Its three wins — −11 kB gzip on a lazy chunk,
zero node overlaps, one selection flag — do not buy that back. Every legibility defect the
swap was meant to cure is Cytoscape-side and cheap. `vis-network` is removed from
`package.json`; the tree returns byte-identical (`git diff --stat` empty).

Two further user rulings, which set what u9 builds:

- **Zoom floor + pan.** Fit is clamped so a node label never falls below a measured floor.
  The whole graph stops being framed on load for dense views and on mobile; the user pans.
- **Labels wrap.** `text-wrap: 'wrap'` with a raised `text-max-width`, replacing the
  `96px` ellipsis that renders `category-B-recommendation` as `gory B reco`.

**Consequence for the layout choice: under a zoom floor, fit-zoom label size stops being a
selection metric.** The tuned arm's smaller `medLbl` is purely its wider spread lowering the
fit zoom, which the floor overrides. What survives the floor is overlaps, crossings and
layout cost — where tuned fcose beats the shipped params 32 vs 103 overlaps and 6/6 vs 0/6
parallel separation at equal cost (146 ms vs 148 ms).

## Renderer-neutral edge-view contract

u9–u13 decide against this. It is renderer-neutral by construction: it names no Cytoscape
type.

```ts
interface EdgeView {
  id: string;
  source: string;
  target: string;
  relation: string;        // the relation label alone
  scope: readonly string[];// ordered; negation and modality ride here (u11/u12)
  state: 'context' | 'highlight';
  dashed: boolean;
  label: string | null;    // null = not shown; when shown, exactly relation + ordered scope
}
```

| id | guarantee | how it is decided |
| --- | --- | --- |
| R1 | Two edges between the same ordered node pair render as distinguishable curves | probe counts separated pairs; the fixtures above give 9 / 6 / 2 |
| R2 | A shown edge label is exactly `relation` + ordered `scope` — never a substring, never reordered | probe reads rendered label text against the `EdgeView` |
| R3 | Selection changes `state` for no edge; the proof highlight is the only writer of `highlight` | select a node, diff the highlighted-edge set |
| R4 | `dashed` is per-edge and carries scope polarity alone | set one edge dashed, diff the canvas, restore, compare bytes |
| R5 | A node label at the settled zoom is at least the measured floor, on every fixture and viewport | probe reads `10 × zoom` against the floor |
| R6 | The seam stays `mountGraphCanvas(container, onSelect) → {update, recenter, destroy}` and `model.ts` keeps zero imports | `rg` census, as in `.claude/rules/graph.md` |
| R7 | A node label is fully readable — wrapped, never ellipsis-truncated | probe asserts no `…` in rendered label text |
