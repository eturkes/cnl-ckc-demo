I want to create a demo to complement `../cnl-ckc/`. You can use any languages or tooling of your choosing; this repo does not demand the level of rigor of `cnl-ckc`, as it is merely a demo. I would like the demo to showcase how the `cnl-ckc` knowledge base can be used to make deterministic Prolog queries. Basically, I'd like the user of the demo to be able to input a prompt in the form of a question and get an answer. Given the current state of `cnl-ckc`, it is only feasible to be able to do this with a small selection of questions. Therefore, I would like you to make an interface that suggests that the future function will allow free input, while for now, when a user clicks in the box, they are simply given a drop-down menu where they can choose a built-in question. Come up with the questions during the development of this demo. Crucially, however, the answers must reflect real Prolog execution, never hard-coding. I'd also like the demo to feature visualizations of how the answer traces back to the source. Lastly, I would like an interactive, navigable network graph showing the semantic relationships between entities of the knowledge base.

Avoid linking directly to `../cnl-ckc`. Rather, you should export anything relevant directly from that project; it should already be equipped to export its knowledge base. If you need to run any commands from within that directory, you have permission to do so.
